1. OVERVIEW & KEY IDEAS

• The paper argues that embeddings for numerical features are an underexplored degree of freedom in tabular deep learning.  
• Two main embedding strategies are proposed:
  – Piecewise Linear Encoding (PLE) with two variants:
    ∙ Quantile-based PLE: uses empirical quantiles to obtain split boundaries.
    ∙ Target-aware (tree-based) PLE: uses supervised discretization (similar to C4.5) per feature.
  – Periodic Embeddings: Use periodic (sinusoidal) activations with trainable pre-activation coefficients (initialized with N(0, σ)) and a tunable multiplier “k”.  
• The embeddings are then fed into different backbones (MLP, ResNet, Transformer) using a “Backbone-Embedding” pattern. For MLP-style models, feature embeddings are computed independently and then concatenated, while for Transformer-like models these tokenized embeddings are passed without extra mixing except that an additional linear layer may be applied to inject feature index information.

2. METHODOLOGY – IMPLEMENTING THE EMBEDDING MODULES

A. Baseline / Simple Differentiable Embeddings  
  • Implement a simple linear layer (optionally with ReLU or LeakyReLU) on each numerical feature.  
  • This “LR” module acts as a baseline.

B. Piecewise Linear Encoding (PLE) Module  
  • Compute bins for each numeric feature (each feature is processed independently):  
   – Quantile Approach:  
    ▪ Use the training set to compute empirical quantiles.
    ▪ Remove any trivial (zero-width) bins.
    ▪ Hyperparameter: number of quantiles (search space UniformInt[2, 256]).  
   – Target-Aware (Tree-Based) Approach:  
    ▪ Fit a one-dimensional decision tree on each feature using the target as guidance.
    ▪ Use parameters similar to “C4.5 discretization”:
     – Maximum number of leaves (UniformInt[2,256]),
     – Minimum samples per leaf (UniformInt[1,128]), and
     – Minimum information gain (LogUniform[1e-9, 0.01]).
  • For each scalar value x, create the PLE encoding vector e = [e₁, …, e_T] according to Equation 1:
   – e_t = 0 if x is below the (t–1)th bin boundary (with t > 1);
   – e_t = 1 if x is above or equal to the t-th bin boundary (with t < T);
   – Otherwise, compute a linear interpolation: (x – bₜ₋₁) / (bₜ – bₜ₋₁).
  • The final feature embedding is given by a trainable linear combination:
    fᵢ(x) = v₀ + Σₜ eₜ · vₜ  
    – Here, v₀ and vₜ are learnable parameters (embedding vectors) for that feature.
  • Optionally, experiment with additional differentiable layers on top of the PLE output (e.g., adding an extra linear or ReLU block).

C. Periodic Embedding Module  
  • For each numerical feature, implement a transformation that uses periodic activations:
   – Example formulation: fᵢ(x) = Linear( sin( k · x + cᵢ ) )  
    – k is a tunable hyperparameter (UniformInt[1, 128]).
    – cᵢ is a trainable parameter for each feature (initialize via N(0, σ) where σ is tuned).
  • Like in the PLE modules, the result can optionally be enhanced by stacking an extra differentiable (e.g., linear) layer that “wraps” the periodic module.
  • Note: The paper’s Equation 2 is brief; you need to choose a periodic function (sin, cosine, or both) and then add the additional linear transformation as suggested.
