[Logic Analysis]
- ['dataset_loader.py', 'Defines the DatasetLoader class which handles loading datasets from local files or online sources. It is responsible for splitting the data into train, validation, and test sets. The module implements preprocessing methods including quantile transformations for numerical features, standardization of regression targets, and one-hot encoding for categorical features. It also computes and caches the bin boundaries for the piecewise linear encoding (for both quantile-based and target-aware approaches).']
- ['model.py', "Defines the Model class and various submodules for embeddings and backbone architectures. This includes:\n- Baseline embedding: simple linear layer(s) with optional activation.\n- Piecewise Linear Encoding (PLE): Implements both quantile-based and target-aware binning. Contains methods to compute e_t values according to Equation 1 and to combine bins with learnable parameters (v0 and vt).\n- Periodic embedding: Implements a module that applies a periodic function (sin or sine+cosine) after scaling input by a tunable multiplier (k) and adding trainable biases (initialized from N(0, σ)).\n- Backbone architectures: Implements MLP, ResNet, and Transformer based on the specifications (e.g., using FT-Transformer design). \nUses PyTorch's nn.Module classes and maintains modular design so that embedding modules can be swapped easily."]
- ['trainer.py', 'Contains the Trainer class, which organizes the training process. Handles the training loop using the AdamW optimizer and a configurable loss function (cross-entropy for classification, MSE for regression). Implements early stopping based on validation metrics (patience set to 16 epochs). Provides methods for training, validating, and saving model checkpoints. Integrates with Optuna for hyperparameter tuning and logging training progress.']
- ['evaluation.py', 'Implements the Evaluation class responsible for running the trained model over the test dataset. Computes evaluation metrics (accuracy or RMSE) and supports producing ensemble results by averaging predictions over multiple runs. Uses the model and data loaded by dataset_loader.py and modules from model.py.']
- ['main.py', 'Acts as the central entry point. This file reads the configuration, initializes the DatasetLoader to load data, creates the Model, passes them to the Trainer for training, and finally uses the Evaluation module to assess final performance. It also manages the hyperparameter tuning process via Optuna and aggregates results over multiple random seeds. It orchestrates the complete runflow by linking all modules together.']
